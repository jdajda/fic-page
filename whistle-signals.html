Whistle Signals

In a gorge, your voice stops at the first bend. The whistle is the one sound that travels — around a corner, along a wall, through water noise. This is the code the international community agreed on so that any group can be understood by any other group.

1 whistle 5 signals Any language

The code

Five signals, one whistle

Count the blasts. That is the entire system — the meaning lives in the number, not in a vocabulary, so it needs no translation.

1×

Stop

Hold position. Everyone freezes where they are.

2×

OK

Acknowledgement. Also used in Italy to mean down rope.

3×

Down Rope

Rope is ready to descend. Also used in Italy to mean OK.

4×

Rope Up

The rope is clear above you. Come up.

3× … 3×

Emergency

Repeated group of blasts, with a pause between groups.

Using the code

It is important to coordinate among all group members before the start of the descent the communication system used. Agree the code out loud, at the top, while everyone can still hear each other — and agree who signals what.

⚠️

Be careful

The whistle communication code used in Italy is a little bit different: there, 2× means down rope and 3× means OK. Confirm which convention your group is using before you go down.

🗣️

Brief the group

Say the code aloud before anyone is clipped in. Assume no shared language; the point of a whistle is that it does not need one.

👂

Answer every call

Every signal expects a reply. A call with no acknowledgement is an unanswered call — treat it as a problem, not a pause.

🚨

Reserve the alarm

The emergency pattern is the only signal that repeats. Keep it for real emergencies so that it always means something.

🖼️
