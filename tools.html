Tools for a safer canyon

Open standards and reference documents developed within the international canyoning community. They exist so that a canyoneer in one country reads the same rating, hears the same whistle signal and marks their rope the same way as anyone else in the world.

5 core tools Open and free Multilingual

Core standards

The reference documents

Five tools that every member association works with. Each one has its own page with the full detail.

🗺️

Canyon Rating

The international canyon rating system: vertical difficulty, aquatic difficulty and commitment, each on an open scale, written as a single code such as 2.3.III.

Open the system → 📣

Whistle Signals

One whistle, five signals. The international communication code used to coordinate a group on ropes, where voice cannot reach.

Open the signals → 🧵

Marking Rope

How to mark the middle of a rope, how to re-mark it after a cut, and how bands are spaced so a length can be read at a glance.

Open the recommendation → 🪢

Harnesses & Anchors

High and low anchor points compared: where the load is carried, and which configuration suits descending versus ascending.

Open the comparison → 📜

FIC Statutes

The founding statutes of the Fédération Internationale de Canyonisme — how the federation is constituted and governed.

Open the PDF ↗ 🚨

Canyon Accident

A shared database and reporting resource for canyon accidents, so that what happens once does not have to happen twice.

Visit the site ↗
